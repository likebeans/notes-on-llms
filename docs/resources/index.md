# 资源库

[技术核验与更新索引](/resources/updates) 汇总本轮重新对照官方资料的知识点、站内章节和验证边界。

资源页优先收录“能追溯到源头”的材料：论文、官方文档/博客、官方课程或维护活跃的开源仓库。二手解读可以帮助理解，但不应该替代原始来源。

## 五类资源

| 分类 | 适合什么时候看 | 入口 |
| --- | --- | --- |
| 论文 | 想确认技术定义、方法来源和实验设定 | [论文](/resources/papers) |
| 视频 | 想快速建立直觉，适合入门和复习 | [视频](/resources/videos) |
| 博客/文档 | 想跟进 API、产品实践和工程建议 | [博客](/resources/blogs) |
| CSDN 全文镜像 | 想按本站结构阅读作者已收录的技术博客原文 | [CSDN 镜像](/resources/csdn) |
| 开源项目 | 想看真实实现、样例和工程结构 | [开源项目](/resources/repos) |

## 使用建议

1. 学新概念：先看一篇综述或课程，再回论文。
2. 做工程：优先看官方文档、Cookbook 和示例仓库。
3. 做面试：把论文贡献压缩成“问题、方法、效果、局限”四句话。
4. 做生产：检查资源发布日期和适用版本，不要复制过期 API。

若发现链接失效或资料过时，可通过 [GitHub 仓库](https://github.com/likebeans/notes-on-llms) 提 issue。

## 按当前问题选择资料类型

| 你需要确认什么 | 先找哪里 | 阅读后留下什么 |
| --- | --- | --- |
| 某方法的定义、公式和实验条件 | 原始论文 | 问题、假设、对照和局限各一句 |
| 当前 API 参数与错误行为 | 固定版本官方文档 | 包版本、最小调用和错误样例 |
| 如何安排模块与状态 | 项目源码和测试 | 一张调用链与状态图 |
| 为什么出现某种工程故障 | 维护者文档、issue 与复盘 | 可在自己环境复现的案例 |
| 第一次建立概念直觉 | 课程和演讲 | 回到主线章节验证的三个问题 |

本站索引是一组学习入口，不保证其中每个项目仍适合新部署。资源页更新时间指本站整理时间，原资料发布日期和适用版本需要分别确认。
