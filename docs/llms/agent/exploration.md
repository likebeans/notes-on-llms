# 探索与发现

> 让智能体主动探索未知领域，发现"未知之未知"

## 🎯 核心概念

> 来源：[Agentic Design Patterns - Exploration and Discovery](https://github.com/ginobefun/agentic-design-patterns-cn)

### 什么是探索与发现？

::: tip 定义
**探索与发现**模式使智能体能够主动寻找新信息、发现新可能性，并识别运行环境中的"未知之未知"，而非仅在预定义解决方案空间内优化。
:::

### 与其他模式的区别

| 反应式/优化 | 探索与发现 |
|-------------|------------|
| 预定义解决方案空间 | 主动进入陌生领域 |
| 利用已有证据 | 提出待验证假设并收集新证据 |
| 被动遵循指令 | 主动探索环境 |
| 优化已知过程 | 发现"未知之未知" |

---

## 📋 六大应用场景

| 场景 | 说明 |
|------|------|
| **科学研究自动化** | 设计实验、分析结果、提出新假设 |
| **游戏和策略生成** | 探索游戏状态、发现涌现策略 |
| **市场研究** | 扫描非结构化数据识别趋势 |
| **安全漏洞发现** | 探测系统发现安全漏洞 |
| **创意内容生成** | 探索风格组合生成艺术作品 |
| **个性化教育** | 根据学生进度优化学习路径 |

## 🔬 案例：Google Co-Scientist

Google 的案例用于说明假设生成、讨论和排序的研究工作流。系统产生的候选假设需要与文献及实验结果核对；不能把自评排名当作科学结论。[原始研究介绍](https://research.google/blog/accelerating-scientific-breakthroughs-with-an-ai-co-scientist/)

### 多智能体架构

| 智能体 | 功能 |
|--------|------|
| **生成智能体** | 通过文献探索生成初始假设 |
| **反思智能体** | 检查合理性、新颖性与已有证据；不替代实验验证 |
| **排名智能体** | Elo评级竞赛模式排序假设 |
| **演化智能体** | 简化概念、优化假设 |
| **邻近智能体** | 聚类相似想法，探索假设空间 |
| **元评审智能体** | 综合见解，识别模式并反馈 |

## 一个可控的探索循环

以“查明检索效果下降原因”为例，先固定数据和评价集，再提出分块、召回过滤、重排三个候选解释。每轮只改变一个关键条件，记录假设、实验设置、结果和反证。Agent 可以提出下一步实验，结论由可重复的观测支持。

探索预算应包括最大候选数、工具调用数、允许访问的数据范围和终止时间。连续若干轮没有新证据、候选高度重复或评估分数没有改善时，返回已有发现与不确定项。它无需无限自我扩展目标。

验收分开看三个数：新增且去重的候选数、被独立证据支持的候选比例、单位验证成本。只统计想法数量会鼓励改写已有想法；只看模型给分会鼓励迎合评审提示。与[反思模式](/llms/agent/reflection)相比，探索主要扩大候选空间，反思主要修订已有候选，两者都需要外部证据。

## 💡 核心要点

### 使用场景

- **开放式、复杂或快速演变**的领域
- 解决方案空间**未完全定义**
- 需要生成**新假设、策略或见解**
- 发现**"未知之未知"**

### 关键特征

| 特征 | 说明 |
|------|------|
| **主动探索** | 不是被动遵循指令 |
| **独立设定子目标** | 自主发现新信息 |
| **多智能体协作** | 每个智能体有特定主动角色 |
| **涌现行为编排** | 追求长期开放式目标 |

### 一句话总结

> 探索模式适合路径未知但目标可约束的任务。生成更多假设不等于发现更多事实，价值取决于后续验证。
