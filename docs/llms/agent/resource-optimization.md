# 资源感知优化

> 动态管理计算、时间和财务资源，在明确质量底线下控制延迟、费用与资源

## 🎯 核心概念

> 来源：[Agentic Design Patterns - Resource-Aware Optimization](https://github.com/ginobefun/agentic-design-patterns-cn)

### 什么是资源感知优化？

::: tip 定义
**资源感知优化**使智能体能够在运行过程中动态监控和管理计算、时间和财务资源，在指定预算内实现目标或优化效率。
:::

### 核心权衡

| 选项A | vs | 选项B |
|-------|:--:|-------|
| 更准确但昂贵的模型 | ↔ | 更快速但便宜的模型 |
| 更精细的响应 | ↔ | 更快速的响应 |
| 高质量输出 | ↔ | 低资源消耗 |

---

## 📋 六大应用场景

| 场景 | 说明 |
|------|------|
| **成本优化LLM使用** | 根据预算选择大型或小型LLM |
| **延迟敏感操作** | 选择更快的推理路径 |
| **能源效率** | 边缘设备优化处理节省电池 |
| **服务可靠性后备** | 主模型不可用时自动切换 |
| **数据使用管理** | 选择摘要数据而非完整下载 |
| **自适应任务分配** | 根据负载自行分配任务 |

---

## 🏗️ 核心架构

### 路由智能体（Router Agent）

对请求复杂性分类，转发到最合适的模型。

```
用户请求 → 路由智能体 → 简单查询 → 快速模型
                      → 复杂查询 → 强大模型
```

### 评论智能体（Critique Agent）

| 功能 | 说明 |
|------|------|
| **自我修正** | 评估输出质量 |
| **性能监控** | 跟踪响应效果 |
| **路由改进** | 优化分类逻辑 |

---

## ⚙️ 九大优化技术

### 1. 动态模型切换

根据任务复杂性选择LLM：简单→轻量模型，复杂→强大模型。

### 2. 自适应工具使用与选择

考虑API成本、延迟、执行时间，为每个子任务选择最高效工具。

### 3. 上下文修剪与摘要

策略性最小化提示Token数，智能摘要和选择性保留信息。

### 4. 主动资源预测

预测未来工作负载，主动分配资源，防止瓶颈。

### 5. 成本敏感探索

多智能体系统中优化通信成本和计算成本。

### 6. 能源高效部署

最小化能源足迹，延长运行时间，降低运行成本。

### 7. 并行化与分布式计算

利用分布式资源增强处理能力和吞吐量。

### 8. 学习型资源分配策略

基于反馈和性能指标，持续优化资源分配。

### 9. 优雅降级和后备机制

预算不足时减少可选步骤、返回有来源的部分结果，或显式停止；不能省略必要验证后仍声称完成。

## 以“每个成功任务的成本”验收优化

单次调用更便宜，不代表整个系统更省。轻量模型若需要三次重试和一次升级，成本可能高于直接调用能力更强的模型。建议按任务记录模型输入/输出费用、工具费用、重试费用和人工处理时间，先对账，再优化。

`每个成功任务的平均成本 = 测试集中所有任务的总成本 / 成功任务数`。同时单列成功率和失败成本；若成功数为零，该指标应标记不可用。比较方案必须使用同一任务集、相同完成标准和预算范围。

| 优化动作 | 可能的反作用 | 验证重点 |
| --- | --- | --- |
| 压缩历史上下文 | 丢失约束、出处或工具调用配对 | 长任务约束保持率、恢复成功率 |
| 缓存工具结果 | 时效或权限变化 | 缓存键包含租户/权限范围、数据版本与过期时间 |
| 增加并发 | 限流与重试放大 | 在途请求、队列长度、p95、限流率 |
| 小模型先处理 | 升级比例过高 | 各难度层成功率、升级总成本 |
| 降低反思轮数 | 漏检关键错误 | 必须通过的业务断言是否保留 |

预算控制应在运行时强制执行：每个 run 设总截止时间、调用次数和费用上限；发起并行任务前预留预算，结束后结算实际用量。达到阈值后的行为必须预先定义，不能仅向模型提示“少花一点”。

## 💡 核心要点

### 使用场景

- **严格财务预算**下的API调用
- **延迟敏感**应用
- **资源受限硬件**（边缘设备）
- 需要**平衡质量与成本**
- 不同任务有**不同资源需求**的工作流

### 一句话总结

> **资源感知优化通过动态管理计算、时间和财务资源，使智能体在现实世界约束下高效运行，实现最佳性能和成本效益的平衡。**
