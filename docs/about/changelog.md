# 更新日志

## 2026-10-08

### 学习体验与技术更新

- 新增可运行知识助手，连接检索、受控工具、执行日志、离线评估和可选 MCP stdio。
- 新增文章检索、主线/镜像筛选、本地收藏、已读记录和继续阅读入口。
- 检索条件和已展开的结果数量随链接保存，刷新或返回列表时自动恢复。
- 目录和搜索链接自动展开目标章节，兼容旧地址与浏览器历史导航。
- 修复滚动触发图表重绘和横向位置重置；正文展开或高度变化时同步更新阅读进度。
- 构建检查覆盖站内链接、章节锚点和本地图片引用，错误会标出来源页面。
- 模块进度区分章节位置与手动完成数；前置知识显示文章标题。
- 修复正文来源链接漏计，按去重外部资料链接统计；单独展示资料复核范围和示例执行状态。
- 新增按工程问题组织的阅读路径；两篇 RAG 长文分层，六大模块补充场景自测。
- 对照官方文档与原始论文更新 MCP 协议、Agent 长任务和评测、结构化输出、GRPO、PEFT 和多模态检索部署。入口见 [技术核验索引](/resources/updates)。

### 全站内容修订

- 按“原理与工程实践并重”优化六大技术模块，补充适用条件、失败诊断与验收练习。
- 修正检索分数、评估指标、训练与多模态说明中的不准确表述；区分教学设定与实测收益。
- 重写 MCP 入门、核心概念和高级功能，固定示例依赖，明确传输、授权和文件访问边界。
- 扩展面试题的回答思路、追问和自测，补充可运行的基础代码练习。
- 补齐指标计算口径、实验与调用记录模板，让学习路径与实践产物相互对应。
- 为 30 篇 CSDN 镜像增加针对性导读，清理代码块残留的语法高亮标签，保留原文观点与来源。

本条记录描述仓库中的内容修订；文字更新不代表全部历史示例已验证，也不代表线上已发布。
